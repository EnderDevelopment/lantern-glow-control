# Minecraft Lantern Brightness Plugin

Lantern Glow Control is a Minecraft plugin for assigning individual brightness levels to lanterns. This lantern brightness plugin lets players set a custom light level from 1 to 15 for each regular or soul lantern, with settings saved across restarts.

## Install

1. Use a Paper server compatible with Minecraft 1.21 and Java 21.
2. Place the plugin JAR in the server’s `plugins` directory.
3. Start or restart the server to load the plugin.

## Use

1. Run `/lantern` or `/lantern menu` to open the brightness menu.
2. Click a brightness level, then right-click the lantern you want to configure. The selected level applies to that lantern.
3. To set a level directly, run `/lantern set <1-15>`, then right-click a lantern.
4. To remove a lantern’s custom brightness, run `/lantern clear` or select the clear option in the menu, then right-click a configured lantern.

The plugin places a Minecraft light block above a configured lantern to provide its selected brightness. The space above the lantern must be air or already contain a light block. Lantern settings are stored in the plugin’s data folder.
